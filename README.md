# Portfolio Website

A responsive personal portfolio built with HTML, CSS, and JavaScript. The site
is lightweight and can be hosted as a static website.

## Features

- Responsive layouts for desktop, tablet, and mobile screens
- Accessible navigation with a mobile menu
- Project cards with expandable details
- Subtle scroll effects with reduced-motion support
- Contact links and a custom SVG favicon

## Project structure

```text
portfolio-starter/
├── index.html
├── README.md
└── assets/
    ├── favicon.svg
    ├── css/style.css
    └── js/main.js
```

## Run locally

Open `index.html` in a browser, or start a local server from the project folder:

```powershell
python -m http.server 8000
```

Then open `http://localhost:8000/`.

No dependencies or build step are required.
